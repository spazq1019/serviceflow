# ServiceFlow

ServiceFlow is a full-stack service discovery and appointment-booking platform built as an agent-assisted product engineering project.

## Project Status

Currently under development.

## Planned Features

- Service catalogue
- Customer authentication
- Appointment availability
- Booking and rescheduling
- Customer dashboard
- Administrator dashboard
- Test payment workflow
- Booking notifications

## Technology Stack

- TypeScript
- React
- Next.js
- Tailwind CSS
- PostgreSQL
- Prisma
- Auth.js
- Zod
- Vitest
- Playwright
